# Вариативная часть. Текстовый редактор на Python.

**Простой текстовый редактор с графическим интерфейсом, написанный на Python с использованием библиотеки Tkinter.**  
Поддерживает базовые операции с текстовыми файлами: создание, открытие, сохранение и сохранение как.
Источником служило видео-туториал, но программа была изменена под более новую версию Python. 

---

## Основные функции

### Операции с файлами:

- **New** (`newFile()`)  
  Создает новый пустой документ с именем "Untitled".  
  Если в редакторе есть несохраненные изменения — они будут потеряны.

- **Open** (`openFile()`)  
  Открывает диалоговое окно для выбора файла.  
  Поддерживает чтение в кодировке UTF-8.  
  При ошибке чтения выводит сообщение "Unable to open file...".

- **Save** (`saveFile()`)  
  Сохраняет текущий файл.  
  Если файл новый (имя "Untitled" или не задано) — автоматически вызывает "Save As".  
  При ошибке сохранения выводит сообщение "Unable to save file...".

- **Save As** (`saveAs()`)  
  Открывает диалоговое окно для выбора места сохранения.  
  Поддерживает указание расширения (по умолчанию `.txt`).  
  Сохраняет в кодировке UTF-8.

- **Quit**  
  Закрывает редактор.

## Технические детали

### Особенности реализации:
- Использует стандартные диалоги Tkinter:
  - `asksaveasfilename` для "Save As"
  - `askopenfilename` для "Open"
- Работа с текстом:
  - Все операции используют индексацию с `1.0` (вместо устаревшего `0.0` в Python 3)
  - Поддержка UTF-8 при чтении/записи
- Глобальная переменная `filename` хранит текущее имя файла

### Обработка ошибок:
- При ошибках ввода/вывода показывает сообщения через `showerror`
- Корректно обрабатывает отмену операций в диалоговых окнах

### Дополнительные функции:
Была добавлена возможность изменения цвета выделенного текста на чёрный, красный, голубой или зелёный.
