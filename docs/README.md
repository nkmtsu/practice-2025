#  Проектная практика

В ходе проектной практики необходимо **разработать сайт** по дисциплине "Проектная деятельность", а также выполнить вариативную часть, а точнее **создать текстовый редактор** на Python.

Основной целью практики является освоение веб-технологий, работы с Git и самостоятельной разработки программного продукта.

##  Технологии, которые были использованы в ходе выполнения проектной практики:

- GitHub
- Markdown
- Hugo (для сайта)
- Python (для текстового редактора)
