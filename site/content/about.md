# О проекте
MathSem - это учебная программа, созданная студентами Московского Политеха, чтобы помочь студентам легче изучать алгебру логики и теорию множеств. Программа доступна для скачивания на сайте и работает на ПК с удобным интерфейсом, построенным на QT.
### Задачи проекта (2 семестр)
**Задачи, связанные с представлением данных в программе, с написанием алгоритмов для построения формул и их анализа:**
1.	Задокументировать код в стиле Doxygen на русском и английском языках.
2.	Разработать окно справки в программе.
3.	Приведение к префиксной и сколемовской нормальной форме (синтаксический анализ формул).
4.	Проанализировать структуру данных для хранения формул в программе, разобраться как формируется файл *.fms.
5.	Проанализировать как записываются формулы в *.docx.
6.	Разобраться, каким образом строятся схемы в VUE.
7.	Определение эквивалентности формул с точностью до замены переменных.
8.	Построить в прототипе программы определение функции, область определения функции, область значения функции, определение отношения, определение графа, транзитивные, симметричные, рефлексивные свойства.
9.	Построить формулу A ⊂ (A ⋃ B) в прототипе программы.

**Задачи для Базы данных:**
1.	Таблица с пользователями.
2.	Таблица с файлами с формулами.
3.	Разработать структуру для хранения формул на сайте и в базе данных.
4.	Выбрать технологии для написания Базы данных и сайта.

**Задачи для сайта:**
1.	Выбрать технологии для разработки сайта.
2.	Разработать прототип сайта в Figma.
3.	Сверстать страницы сайта по прототипу.
4.	Написать бэкенд для реализации регистрации, добавления отзывов.
5.	Создать базу данных для хранения построенных пользователями формул, интегрировать ее в сайт.

Сайт проекта: https://mathsem.netlify.app
